# Smart Farming Website

## Overview
A responsive Smart Farming web application built using HTML, CSS, JavaScript, and Chart.js to monitor soil moisture and support irrigation planning.

## Features
- Responsive Design
- Soil Moisture Dashboard
- Weather-based Prediction
- Interactive Charts
- User-friendly Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
